# Deep Neural Network Feature Visualisation & Adversarial Attack 

## Slide 1: Title Slide 

<mark>In this video lesson, we will look at how to visualise the image features learned by the convolutional neural network during training. We will also briefly discuss adversarial attacks on neural networks and the limits of generalisation of neural networks.</mark> 

## Slide 2: Introduction 

<mark>For far we have looked at neural networks as image classifiers and have noted that the convolution layers learn features during training. However it isn’t at all transparent what networks have learned during training and what image features they respond to when performing inference on a test image. By investigating learned features, neural networks can be made more explainable which helps when deploying models in real world applications. In the first part of this lesson we will look at 4 techniques that help understand what the network has learned. We will give a quick overview of the techniques and cover them in more detail over the next few slides. The first technique is reconstruction, which is also known as inversion. In this technique shown in figure (a) an image of a monkey is first input to a neural network and feature maps generated by the convolution and fully connected layers. Using only the information from individual feature maps, the input image is reconstructed.  The deeper the layer used for reconstruction, the less accurate and more abstract the reconstruction. This is consistent with the network retaining more semantic concepts in deep layers. In the Visualisation technique with activation maximisation, the detail of image features that individual neurons respond most strongly too can be determined. It is seen in figure (b) that early layers respond to simple features and deeper layers to more complex object like features. In the style transfer technique shown in figure (c) it is found that it is possible to transfer the style of one image, usually an artwork to the content of another image. This is extremely difficult to perform using traditional computer vision techniques, but it is possible with a trained neural network due to learned texture and content information. The final technique we will look at is the Deep Dreams, in this case for a given input image, the learned image features that the network is responding to in the image are emphasised in the input image as shown in figure (d), which produces the “Dream like” or hallucinatory images which inspired the name of this technique.</mark> 

## Slide 3: Reconstruction 

In the reconstruction technique we want to determine what information about the image is retained by the various feature maps of the network. Figure (a) and the algorithm shows how we can perform the reconstruction. We first input the target image into the network and store the features produced at the layer of interest. In this case the layer of interest is convolution layer 3. An image of random noise is then input to the network, and the features at the same conv3 layer are obtained. These new features are compared with the set of features from the target image in a loss function. Using the gradient descent algorithm, the goal is to update the random noise image on each iteration such that the loss approaches zero and random noise image eventually converges to a final image resembling the target image. Some regularisation terms are also applied to the loss, to help generate natural looking images. As can be seen in figure (b) the reconstruction from the early convolution layers is very high quality, showing that the early stages of the network finds many low level features enabling accurate image reconstruction. In deeper layers the reconstruction is less 

accurate, eventually only an abstract composition of parts of the image can be reconstructed. This is consistent with the deep layers of the network learning concepts about objects from large numbers of training images. 

## Slide 4: Visualisation with Activation Maximisation 

<mark>In the visualisation technique, we want to visualise the features that the convolutional layers have learned. One common method of visualising features is known as activation maximisation. This method involves choosing a neuron, channel or layer at some point in the network and determining what input image will maximise the output of that neuron. The final image that we find corresponds to the image feature the neuron would ideally respond too most strongly if it appeared in a real image. The figure (a) and algorithm on the slide shows how we can find these input images. We start with an image composed of random noise and pass this into the network. We monitor the value of the neuron of interest. This value is passed to a gradient ascent algorithm. The gradient ascent algorithm can then be used to update the pixel values in the image to further increase the value of the neuron. We also have to add a regularisation penalty function to the output of the neuron to ensure that the image we find is natural looking, as it is possible that there are many random noisy patterns that still maximise the neuron. It is important to note that in this case we are using gradient ascent rather than gradient descent, as we want to maximise the loss which is just the output value of the neuron. In figure (b)  we show the result of feature visualisation of the convolutional layers from the VGG-16 network. We note that these images are produced by maximising the activation of one point in a feature map from the different layers of the network. It should be noted that the size of the obtained images increases as you go deeper into the network. This is because the receptive field of the neurons is increasing.  It is seen that the early layers respond strongly to simple features, such as blobs of colour and edge-like features.  The next layers respond to features consisting of complex patterns, possibly corresponding to textures in images. In the deeper layers, the filters start to resemble objects or parts of objects.</mark> 

## Slide 5: Visualisation for Understanding 

<mark>Visualising the convolutional layers in a network also helps us to understand what the network is looking for in input images for specific classes. On this slide, we compare images produced by activation maximisation, to images selected from the training set that the neuron of interest also responds strongly to. As can be seen in the captions for each of these images, the neural network may recognise objects by finding certain properties that are common to the training images, such as the fluffiness of clouds or the presence of sky in the images of buildings. Therefore, in many cases the network may not really be recognising the object itself, but can be relying on other features that occur with the class or object to perform recognition. This may result in confusion between classes or similar objects if the network is deployed in a real world application.</mark> 

## Slide 6: Style Transfer Concepts 

<mark>As mentioned in the introduction the Style Transfer technique allows the transfer of the style of one image, usually an artwork to the content image. Style transfer is very difficult to achieve with traditional computer vision techniques, but can be achieved with a pre-trained neural network. The style transfer is possible due to the information learned by the neural network. As we saw in the reconstruction task, and as shown in the lower part of figure (a), the early layers of the network contain enough information to accurately reconstruct an image. The deeper layers contain content information about objects and their relationship but don’t contain fine detail about the content. In</mark> 

<mark>addition to the content information, style or texture information about any image is retained by the network. Texture information is obtained by getting the inner product of the feature maps as shown in the upper part of figure (a). As can be seen in the images, texture at different scales is obtained, with small scales from early layers and large scales from deeper layers. The style and content images shown in the figure are obtained using the reconstruction technique. On the next slide we will show how to perform the actual style transfer.</mark> 

## Slide 7: Training Style Transfer 

<mark>In order to create the style transferred image we initially start by passing the content image through the pre-trained network and store the values of a deep feature map, the values of the conv 4 layer is stored in this case. The desired style image then is passed through the network and the texture information from all the convolution layers is obtained by getting the inner product of the individual feature maps. This texture information is then stored. A random noise image is then applied to the network, the outputs of the feature maps are stored, the texture information is obtained from all convolution layers and the content information from the conv 4 layer. These outputs are then compared in the loss function against the style and content information from the earlier steps with the style and content images. The gradient descent algorithm adjusts the pixels of the random noise image to simultaneously minimise both the style and content loss. The random noise image will gradually converge to an image with the content of the original content image but in the style of the style image. The style transfer technique not only demonstrates that both content and style information are available in the layers of the network but also that this information can be combined into novel images.</mark> 

## Slide 8: Deep Dreams 

<mark>The Deep Dreams technique is similar to activation maximisation in that we try to determine what image features the neurons of the network will respond strongly too. In the deep dreams technique shown in figure (a) a content image is applied to the network instead of random noise. This content image initially forces the network to respond to features in the image. With maximisation of the loss and gradient ascent applied to the image, these image features become amplified. In the deep dreams technique the outputs of many layers are maximised simultaneously which will tends to result in multiple features being amplified in the image.  As shown in figure (b) specific content images will bias the network towards certain features, we can see that images with clear horizon lines results in towers and pagodas, trees can result in features of buildings and leaves result in features of birds and insects. These results indicate associations of the image features such as horizon lines and trees with concepts that the network has learned such as towers and buildings. The deep dreams technique was also one of the earliest examples of AI generated art. By applying the algorithm iteratively and zooming on regions of the resulting images before iterating, a series of abstract images related to learned features can be generated as shown in figure (c).</mark> 

## Slide 9: Adversarial Attack 

<mark>In this section of the course we have seen the incredible performance that can be achieved on the image classification task. Trained neural networks appear to generalise very well and can achieve high accuracy on test images. However before deploying a neural network into an application, particularly a safety critical application, we need to understand the robustness of neural networks. On this slide we will 1</mark><sup>st</sup> <mark>consider the susceptibility of neural networks to adversarial attack and shortly also consider the limitations of generalisation of neural networks. Adversarial examples seek to trick the neural network into misclassifying an input image by manipulating the input image. As we can see in the example on the slide, the image of the panda just requires a very small amount of</mark> 

<mark>a noisy pattern to be added to it in order for the network to output a completely different label with a higher confidence than the original prediction! From the point of view of a human observer the addition of the noise has not changed the image in any discernible fashion. The addition of the noise to the image has forced the wrong output neuron to be activated, disturbingly only a small amount of noise needs to be added to cause this misclassification. Due to the internal structure of the neural network (that is lots of multiplication and non-linear activation stages) many small changes at the input can lead to large changes in the output. It should also be noted that adversarial attacks that affect one network can actually affect other networks as well. It is an active area of research to try to develop more robust networks that can withstand adversarial attacks.</mark>

## Slide 11: Lack of Generalisation 

<mark>In contrast to the adversarial attack where we are deliberately seeking to force the network to misclassify an image, a trained neural network will potentially make errors in many situations due to a lack of ability to generalise. We have previously discussed how during training of a neural network we do not want it to overfit to the training dataset and therefore want it to be able to generalise well on the test dataset. Usually however the training and test datasets are drawn from the same pool of images and share many characteristics in common. If we test a network with images from outside the test and training pool we can find unexpected behaviour. One example of this behaviour that has been discovered is that the network is easily fooled by changes in pose of object that it can otherwise easily recognise. As we can see in the examples on the slide, the school bus, scooter and fire truck are all recognised when in a position that corresponds to what would have likely been seen in the Imagenet training set, however once the pose of these objects is varied misclassification occurs. Once again this highlights how deploying a neural network in a safety critical application could be dangerous, as unexpected behaviour could result from misclassification. For example the failure of a self driving car not to recognise a pedestrian lying in the road due to a different orientation of the pedestrian compared to it's training data would obviously be an extremely dangerous error.</mark>
