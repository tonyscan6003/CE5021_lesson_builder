## Slide 2: <mark>Introduction</mark> 

<mark>Convolutional neural networks are the main building blocks in deep neural networks for imaging. ## Slide 3: Multiple Channels 

We have previously discussed convolution with a 2 dimensional single channel or greyscale image, with a single kernel. This is shown in figure (a). In modern convolutional neural networks the input is usually a colour RGB input with 3 channels as shown in figure (b). In order to perform convolution with this image, the kernel is required to have the same number of channels as the image. Each channel of the kernel is convolved with the appropriate channel of the image, the results are then summed to produce on output channel. We will see in detail on the next slide how a convolution with multiple channels is performed. We often use the term feature map to describe the convolution output produced in convolutional neural networks, as the output will show where in the input image features corresponding to the kernel are located.  In the deeper layers of CNNs the number of input channels can be large, convolution is performed similar to the RGB case. As shown in figure (c) with an input feature map with C channels the kernel must also have C channels, and once again a single feature map results. We note that the input has a spatial size of 𝑚 × 𝑛 and the kernel has a size of 𝑘 × 𝑘 . The spatial size of the output feature map is 𝑚′ × 𝑛′ , the size can be calculated using the same relationships we discussed in the earlier lesson on convolution, by considering the 2D convolution between the input channels and a kernel channel. 

## Slide 4: Example Conv. Multiple Input Channels 

<mark>On this slide, we will look in detail at an example of convolution with multiple input channels. As shown in figure (a), a 3 channel R, G, B input image is convolved with a kernel, that also has 3 channels to produce a single output feature map. As mentioned on the previous slide, the kernel must have the same number of channels as the input image in order for the convolution to take place. As can be seen in figure (b), the convolution proceeds as a series of simple 2D convolutions. Each channel of the input is first convolved with the corresponding channel from the kernel. As the input image is of size 3 x 3 and the kernel is of size 2 x 2, there is no padding and a stride of 1 is assumed, then an output of size 2 x 2 results for the red, green and blue channels. These 3 output images are summed to create the final output feature map.</mark> 

## Slide 5: Multiple Kernels 

Deep Convolutional Neural Networks use parallel kernels to increase the number of parameters of the CNN. This allows many complex image features to be learned, improving the ability of the network to classify or detect objects in real world images. Figure (a) shows the typical convolution operation usually corresponding to one convolution layer seen in Deep CNNs. The input is a multichannel feature map with C channels, this input is convolved with N kernels. Each kernel must have the same number of channels as the input and we can see this in the diagram. Each individual kernel is convolved with the input in the manner discussed on the last slide, therefore each channel of the kernel is convolved with the matching channel of the input, and the results are then summed to produce one 2D feature map. It is very important to note that as we have N kernels, there will be N parallel feature maps produced. The output feature map sizes are governed by the same relationships as 2D convolution. The padding may be set as Valid, Same or full depending on the particular case. 

## Slide 6: Volumes 

In the examples from the last few slides, we displayed the individual feature maps or channels for the input and output of a convolution operation. We also explicitly displayed each of the convolution kernels and showed each kernel with C channels corresponding to the number of channels of the input feature map. In deep convolutional neural networks where the convolution operations involve hundreds of feature maps, it is not practical to draw individual feature maps or kernels in diagrams of neural network architectures. Instead we often use a more compact visual representation where all the feature maps are combined into “volumes”, figure (a) shows an example of a convolution operation on an m x n x C input volume, and the production of an m’ x n’ x N output volume. The volumes give us the spatial dimensions of the feature maps aswell as the number of feature maps. In this example a projection of a k x k convolution kernel onto the input volume is shown, this is sometimes done to indicate the presence of a convolution operation. Note that when looking at examples of neural networks architecture drawn as volumes, we need to infer from the displayed dimensions the exact details of the computational operations. In this example we see that we have kernels of size k x k operating on C input channels or feature maps, so we know the convolution kernels have to have the same number of channels. The output volume has N channels, so there must be N individual kernels to produce N output feature maps. Therefore we have N kernels of size k x k x C. 

## Slide 7: Convolution Parameters 

On this slide we will investigate calculating the number of parameters used in a multi-channel, multikernel convolution. The number of parameters is associated with the convolution kernel, in a simple 2D convolution with a 3 x 3 kernel, there are 9 parameters. In a complex convolution there are multiple kernels and multiple channels which greatly increase the number of parameters. We can usually determine the number of parameters by inspection of the convolution operation. Figure (a) shows an example of a convolution operation with an input volume of spatial size m x n with C channels. This input is convolved with a kernel of size k x k, the result is an output of size m’ x n’ with N channels. From the diagram we see that the number of output channels is equal to N, this means that we must have N kernels, as there is always one kernel per output feature map channel. The number of channels in the input feature map C corresponds to the number of channels in the kernel and we can also see the spatial size of the kernel is k x k. We calculate the number of parameters as the product of the number of kernels N, by the number of channels C, by the size of the kernel k x k. To get the correct number of parameters, we should also include a bias parameter, which is added to each feature map in a convolutional neural network. We will discuss how convolution operations can be formed into a neural network in the next lesson. 

### Slide 8: Convolution Operations 

In addition to calculating the number of parameters we would also like to calculate the number of multiplications that are required to carry out a complex convolution. Figure (a) shows the same convolution as the previous slide, so we have already calculated the number of parameters as N x k x k x C. The number of multiplications depends on the number of times the kernels are multiplied against each region of the image. As each spatial position in the output feature maps corresponds to a position where the kernel was located in the input, we can use this as a quick shortcut to find the number kernel positions in the input. This shortcut avoids us needing to know the exact stride and padding used in the convolution to work out the multiplication. The total number of multiplications is therefore equal to the number of convolution positions which is equal to m’ x n’ multiplied by the number of parameters N x k x k x C. We note that we don’t include the bias parameter as this is added to each kernel, we are more concerned with multiplication as this is more computationally expensive than addition. We can see that convolution can result in a large amount of multiplications taking place, however this is computationally efficient to perform as the same parameters are used multiple times. 

### Slide 9: 1 x 1 Convolution 

On this slide we discuss the particular case of 1 x 1 convolution which is often seen in convolutional neural networks. So far we have seen examples of convolution with small kernels such as 3 x 3 and 2 x 2. The use of larger kernels is seen in image processing, but in convolutional neural networks smaller kernels such as 3 x 3 are preferred as it reduces the total amount of computation. As we saw on the last slides number of parameters is dependent on k x k or kernel size squared) which is a factor in the total number of multiplications. The kernel can be reduced down to a minimum of size 1 x 1, this leads to the smallest possible number of parameters.  1 x 1 convolutions are computed in the same manner as convolutions with larger kernels. Figure (a) shows a 1 x 1 convolution with a multiple channel input and a single 1 x 1 kernel, which results in a single output feature map. Figure (b) shows convolution with a multi-channel input and multiple 1 x 1 kernels, this produces N output feature maps. The key properties of 1 x 1 convolution is that it does not require any padding and the input and output feature map size will be the same. As we will see in the next slide 1 x 1 convolution is often used to form a bottleneck layer that can reduce the number of channels and help reduce computation in a neural network. 

### Slide 10: Bottleneck Convolution. 

As we just mentioned, 1 x 1 convolutions are often used as a so called “bottleneck” convolution to help reduce computation. We will show how this works with an example. In figure (a) we see a 3 x 3 convolution with an input feature map of size m x n, where n,m are 32. The input feature map also has C=24 channels, this is convolved with N=12 kernels. We are told that this convolution uses “Same” padding with a stride of 1, so the output feature map size n’,m’ is also 32.  From the previous slides we know we can calculate the total number of multiplications as N x k x k x C x n’ x m’ which will be 12 x 3 x 3 x 24 x 32 x 32=2,654,308. In the bottleneck convolution case shown in figure (b), a 1 x 1 convolution is inserted before the 3 x 3 convolution. The 1 x 1 convolution reduces the channel number from C=24 to P=12 in the new intermediate feature map. The 3 x 3 convolution is now applied to this intermediate feature map with the lower number of channels, which reduces the computation due to the 3 x 3 convolution.  All the feature maps will have the same size, the input and intermediate feature map will be same size as 1 x 1 convolution does not change spatial size. The output feature map will be the same size as the input and intermediate feature map if “Same” padding is used with the 3 x 3 kernel. We can calculate the individual number of parameters for the 1 x 1 and 3 x 3 convolutions separately and then add the result to get the total number of 

multiplication. For the 1 x 1 convolution the number of parameters will be C x 1 x 1 x P which is 24 x 12 =288. The number of multiplications will be 288 multiplied by the size of the intermediate feature map which 288 x 32 x 32= 294,912. For the 3 x 3 convolution the number of parameters will be: the number of kernel channels multiplied by the kernel size, times the number of kernels which will be 12 x 3 x 3 x 12 which equals 1296. We then multiply this by the size of the output feature map size, which will be 1296 x 32 x 32 = 1,327,104. Adding the multiplications for the two convolutions gives a total of 1,622,016 multiplications, which is less than the original non-bottleneck case. Including the efficient 1 x 1 convolution to reduce the number of channels seen by the more computationally expensive 3 x 3 convolution has the effect of reducing the overall computation, compared to the non-bottleneck case.
