## Slide 2: <mark>Introduction</mark> 

<mark>The Convolution operation as it applies to image processing, allows modification of an image by a kernel or filter. Figure (a) shows the example of convolution of a guassian kernel with an image to produce a blurred image. Convolution is a linear operation, every point in the image is multiplied by the same set of values. Convolution is widely used in image processing to perform many operations on images, not only  blurring, but sharpening, finding edges, circular patches etc. 2D Convolution is the core operation in convolutional neural networks. We will spend time in the next few lessons understanding basic 2D convolution as well as advanced convolution and finally how the convolution operation is used in deep neural networks.</mark> 

## Slide 3: <mark>2D Convolution Operation</mark> 

Convolution is defined as the multiplication of an image with a reversed and shifted kernel. Before further considering the mathematical definition of convolution, we will see on this slide that manually performing convolution between an image and a kernel is very straightforward. As stated in the definition, convolution is performed between an image and a kernel. Initially the kernel must be reversed.  This process is shown in figure (a), where the elements of the rows of the 3 x 3 kernel are first reversed (this is the horizontal flip) and then the elements of the columns are reversed (this is the vertical flip). In figure (b) we see an example of the 2D convolution of a 2 x 2 matrix with a 2 x 2 kernel. In this case reversing the 2 x 2 kernel produces the same matrix. So we say that this 2 x 2 kernel has the property of being symmetric. Figure (b) shows the process of shifting the kernel. This involves sliding the kernel across the image and performing elementwise multiplication and sum at each possible x,y position. The output or filtered image is produced from these individual results. We note that a ring of zero values is placed around the image, this is known as padding and it allows the kernel to be slid from a position where it is just overlapping the image, across the image and out to positions on the other side of the image where it again just overlaps the image. As we will see on the next slide the shifting of the kernel is mathematically defined from minus infinity to plus infinity along both axis, however since  the image has only a set number of values greater than zero, we only need to calculate shifts of the kernel that just overlap the image.

## Slide 5: <mark>Zero Padding.</mark> 

As we have mentioned on the last two slides, convolution is defined from −∞ to +∞ and unless otherwise stated we should always slide the kernel  to positions where it just overlaps the image, we can pad the image with the required number of zeros to allow this. We do note that padding with zeros can create some edge effects, these won’t be significant with a small kernel on a big image. As shown in figure (a) the size of the output image can change with a convolution operation. In this case a 4 x 4 input image is convolved with a 3 x 3 kernel, as there are no constraints given we will assume that we need to add 2 rings of padding to the image so that the kernel just overlaps the image. This results in an output image of size 6 x 6 which is a larger size than the input image. In practice when using convolution operations in deep neural networks, we will often choose specific amounts of padding to obtain a particular output size. A common situation is to ensure the input image and output image are the same size after convolution. In the example shown in figure (b) if only one ring of padding is used, in this case then we can make input and output the same size. 

## Slide 6: <mark>Stride</mark> 

<mark>In addition to padding, stride is another important concept that affects the result of convolution operations. In the previous examples of convolution shown in this lesson we have slid the kernel around the input image, with a step of 1 pixel. A step of 1 is in accordance with the mathematical definition of convolution. However we will see in real convolutional neural networks the use of step sizes greater than 1. This is often done to downsample an image or feature map. In the example shown in figure (a), we convolve a 2 x 2 kernel with a 6 x 6 image, but with a stride of 2 and assume no zero padding in this case. As shown on the diagram, there are only three kernel positions before we reach the end of the image. It is the same in the vertical direction and the image is now reduced in size by a factor of two resulting in a 3 x 3 image. Using convolution with a larger stride also results in less computation than a stride of 1.</mark> 

## Slide 7: Pooling 

<mark>Another important operation in convolutional neural networks is pooling. The pooling operation is similar to convolution in that the same operation is applied stepwise over the image; however, there is no multiplication with a kernel. Instead, a pooling operation takes place. This can be a linear or non-linear operation. As shown in the figures (a) and (b), there are two types of pooling operation. The Max pooling operation (which is non-linear) takes maximum value of the pixels in the region. In the case of Average pooling, the average value of the pixels in the small window are returned. Pooling is used to aggregate information in an image or feature maps so typically, a stride of 2 is used for pooling to achieve the reduction in size.</mark>

As we have already seen in this lesson there are many possible variations of convolution depending on the size of the image, the size of the kernel, the amount of padding to be used and the stride. In designing neural networks we want to be able to quickly determine the output image size without going through the time consuming process of performing the convolution manually to determine the result. There is no universal formula that will always allow us to calculate the output size, instead we must use an appropriate formula for each specific case. ## Slide 10: Cross Correlation. 

Before we conclude this lesson we will also take a brief  look at the related operation of cross correlation. This is mathematically similar to the convolution operation but does not require the kernel to be reversed. Cross correlation measures the similarity of the image and kernel, the output image produced with cross correlation will have higher values in regions where the image is similar to the kernel. In image processing the kernel is often symmetric, so the kernel is not changed by reversal. Figures (a) and (b) show the process of reversing asymmetrical and symmetrical kernels. With a symmetrical kernel the result produced by correlation and convolution is the same.
