## Slide 2: Segmentation 

<mark>Earlier in the module, we looked at some simple methods of segmenting images, such as the watershed algorithm and segmentation with the mean shift algorithm. These basic segmentation schemes divide images into regions, generally based on a similarity of pixels. In semantic segmentation as can be seen in figure (a), the image is also divided into regions. However, in this case, each pixel in the image is assigned a specific class based on the underlying object the pixel belongs to. Semantic segmentation can be considered to be the same as the image classification, but with an individual class prediction at each pixel. In the related task of instance segmentation, information generated by object detection is combined with semantic segmentation. In this case, multiple instances of objects such as people seen in figure (b) are individually segmented. Instance segmentation has becomes the key task in competitions, such as the that run on with Microsoft Common Objects in Context (COCO) dataset, as it is more challenging than just building a system to perform either semantic segmentation or object detection.</mark> 

## Slide 3: Datasets 

<mark>As with object detection, there are many datasets available for semantic segmentation. Developing datasets for semantic segmentation is difficult, as it requires time-consuming human annotation of scenes. Many image classification datasets also contain semantic annotations, for example the Pascal VoC. As we saw on the last slide and as shown in figure (a), the Microsoft COCO dataset contains annotations suitable for instance segmentation. Another important dataset developed specifically for segmentation is the ADE20K dataset, which as can be seen in figure (b). This contains annotations for regular semantic segmentation, but also contains annotations for object parts and also parts of faces. Semantic segmentation is a very important component of autonomous driving systems, as highly detailed representations of the locations of objects in the environment are required. So datasets for driving scene segmentation such as cityscapes and KITTI (shown in figure c) have been developed to help drive forward this technology. There are also many other segmentation datasets for other applications. ## Slide 4: Segmentation Network Output 

<mark>On this slide, we will briefly discuss the output of a neural network designed for semantic segmentation. In the image classification and object detection networks tasks, we generally output a vector of class probabilities. As shown in figure (a), the detected class is usually the one with the highest class probability. We often apply an argmax operation across the vector to find the index of the highest probability class. As we mentioned earlier, semantic segmentation involves making a class prediction for each pixel in the image. Therefore, as shown in figure (b), it is necessary to</mark> 

<mark>output a H x W x Nclasses tensor, the argmax operation is applied across all classes at each pixel position to find the index of the highest class probability for each pixel. The detected class information is gathered into a single RGB image, with a false colour assigned to each class. This produces the type of images we have seen in earlier slides.</mark> 

## Slide 5: Evaluating Semantic Segmentation 

<mark>In semantic segmentation, the intersection over union (IoU) metric is the primary method of evaluating the performance of a semantic segmentation system. The IoU is calculated for each class at a pixel level. The IoU may be expressed as a fraction, as shown in the equation. The true positives are divided by the sum of the true positives, false positives and false negatives. As can be seen in the figures (a) to (c) on the slide, if the ground truth and predicted segmentation overlap we have a true positive, as shown by the green dot. If the prediction fails to predict a pixel, a false negative is recorded. If the prediction incorrectly predicts a pixel, a false positive is recorded. The IoU is obtained for each class in the image, and a mean value is calculated. The IoU is the same metric as used for object detection. It can be seen that we just obtain the ratio of the intersecting area and overlapping area between the ground truth and the prediction.</mark> 

## Slide 6: Fully Convolutional Networks 

<mark>The first neural network based semantic segmentation system that we will discuss is the fully convolutional network (FCN). This was not the first system to attempt to use neural networks for semantic segmentation, but this system was reasonably simple and capable of being trained end-toend and is recognised as an important development in the field. Similar architectures were as used by many later semantic segmentation systems. The FCN is based on a pre-trained AlexNet. As shown in figure (a), image classification networks such as AlexNet are designed to aggregate the information from across the image into an output feature map by using several convolution stages. This output feature map is then converted into the vector of class probabilities by a full connected network. In the networks designed for object detection, we saw how we could use the information from the output feature map to predict object classes. In a network for semantic segmentation, we are required to predict the class of each pixel. In order to achieve this goal, the authors of FCN had to modify AlexNet. Firstly, as shown in figure (b), the fully connected stages of AlexNet are converted into convolutional stages; this is similar to what we saw in the overfeat and SSD networks. Thus, the network is now fully convolutional. By doing this, the network can have arbitrary sized inputs. However, at this point in the network while the semantic content about the image is high, the spatial information is greatly reduced as the feature map spatial dimensions are very coarse. Therefore, In order to produce the required output pixel level predictions it is necessary to upsample the output of the network. As we can see in figure (b), there are several output paths for the network, with different names depending on the degree of upsampling. The upsampling operation is performed with transpose convolutions, which we will discuss on the next slide. As we can see in figure (c), if we just directly upsample the output of the network by a factor of 32 the output produced is ill defined. A key finding by the FCN authors was that by using feedforward skip connections from earlier stages in the network, the spatial information that is still present in these earlier stages can be used to improve the quality of the prediction. This is again seen in figure (c).</mark> 

## Slide 7: Transpose Convolution I 

<mark>In these next two slides, we will discuss the important transpose convolution operation, which is used by FCN and many other networks to upsample output feature maps. Firstly, we must recognise that convolution can be performed as a matrix multiplication operation. As we can see on the slide, If we have a 3 x 3 matrix (a), which is convolved with a 2 x 2 kernel (b), this simple operation would yield a 2 x 2 matrix as the kernel is stepped around the input. However, this convolution operation can be written as a matrix multiplication, shown in figure (c). The 3 x 3 input matrix is reshaped as 9 x 1 vector. This vector can be multiplied by a 4 x 9 matrix containing repeated values from the kernel, which gives a 4 x 1 output. This output is then reshaped into the expected 2 x 2 matrix. We can obtain the transpose of the 4 x9 matrix yielding a 9 x 4 matrix. This transpose matrix can be multiplied by a 4 x 1 matrix, yielding a 9 x 1 matrix. This 9 x 1 can be reshaped into a 3 x 3 matrix. Thus, for any kernel we can perform either a regular convolution or a transpose convolution, as shown. Regular convolution always leads to reducing spatial dimensions and a transpose convolution leads to an increase in spatial dimension. Transpose convolution is also used in the backpropagation algorithm.</mark> 

## Slide 8: Encoder-Decoder Network 

<mark>In deep learning software frameworks, such as pytorch and keras, transpose convolution is not performed as shown on the previous slide. Instead, transpose convolution is emulated by direct convolution, and weights learned for upsampling along with the other weights in the network. The key step obtained in this emulation is the output of a larger output feature map. This emulated transpose convolution is also known as fractionally strided convolution. Figure (a) shows the convolution of a 3 x 3 kernel with a 4 x 4 input. The result is a 2 x 2 output. If we want to obtain the transpose of this convolution, then as shown in figure (b), the 2 x 2 input must yield a 4 x 4 output. This can be achieve with a direct convolution by padding two zeros at either side of the input and performing convolution with a 3 x 3 kernel, which yields a 4 x 4 output. In the second example shown in figures (c&d), a 5 x 5 input is convolved with a 3 x 3 kernel with stride equal to 2. In order to reverse this operation and obtain a 5 x 5 output, a zero is inserted between the samples as well as padding zeros. A direction convolution with a 3 x 3 kernel of stride 1 then gives a 5 x 5 output. The second example is more commonly encountered in semantic segmentation systems, as convolution with stride 2 is used for downsampling and a fractional strided convolution is used for upsampling.</mark> 

## Slide 9: Encoder-Decoder Network 

<mark>Encoder decoder networks are an extension of the fully convolutional network that can be used for semantic segregation. The papers Deconvnet and Segnet simultaneously proposed the same architecture shown in figure (a), where a complete decoding network is included after the encoding portion of the network. These networks use the encoding or downsampling part of VGG16 and learn the decoding or upsampling part with end-to-end training. In order to obtain good quality prediction, these networks retain and re-use the spatial information that is normally discarded by pooling stages in the encoder. As can be seen in figure (b), during a regular max pooling operation, the largest activation value in each quadrant is retained. As we mentioned in an earlier lecture, pooling operations reduce the output feature map size and also give the network translational invariance, but the spatial information is lost. In the encoder decoder networks, the spatial position of the max pool values are stored during pooling. Later in the decoder part of the network an unpooling operation can be applied, where the input values to the un-pool operation are assigned to positions in the un-pooled feature map based on the stored spatial information from the corresponding pooling operation. The other elements in the un-pooling output map remain zero. A transpose convolution operation can be used as shown in figure (c) to interpolate this sparse output</mark> 

<mark>feature map. The FCN network did not use any un-pooling, but only upsampled the feature maps. The un-pooling helps to recover spatial information and allows these networks to recover finer detail than FCN. It must be noted that un-pooling operations are not standard operations in most deep learning frameworks, and may difficult to implement.</mark> 

## Slide 10: U-Net 

<mark>Another very well know encoder decoder network is the U-Net. In contrast to the examples on the last slide, the U-Net does not use un-pooling layers. Instead, like FCN, it uses skip connections. The skip connections allow the spatial information in the encoding path to be transferred to the decoding path. The U-Net also uses concatenation of the feature maps. Like in object detection with RCNN, the U-Net architecture can be used as a framework, and the approach used to convert any image classification network into a segmentation network.</mark>
