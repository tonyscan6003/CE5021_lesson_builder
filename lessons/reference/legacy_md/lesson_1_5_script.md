## Slide 2: Supervised Learning 

Supervised learning is the dominant learning paradigm used in computer vision, and is used to train simple classifiers right up to the state-of the art Deep Learning systems. Supervised learning is the formalisation of the concept of learning from examples, which is how Human beings tend to learn. The system that we are training will learn from labelled examples in the training set. The presence of labelled training data, is the defining feature of supervised learning. Figure (a) shows a general supervised learning approach for classical computer vision, in this case we will assume that we are training a classifier to perform image classification. The first step consists of converting images to a more abstract representation and sending the resulting feature vectors a classifier. The classifier is then trained on the feature vector data, during training internal parameters of the classifier are updated using an optimisation algorithm. ## Slide 3: Deep Learning 

As we have mentioned in the introduction to the module, deep learning involves using “deep” models, that is large neural network models with many convolution layers. Secondly in the deep learning approach, deep neural networks learn features from images in an “end to end” fashion. This is the key difference from earlier machine learning approaches. In classical computer vision (as shown on the previous slide) the features had to be “engineered” , so the computer vision engineer had to use or develop an approach to find discriminative image features and then convert these images to an abstract representation that the classifier could successfully learn from. In the deep learning approach this feature learning is done automatically, the fully connected layers forming the classifier part of the network are also optimised simultaneously. Deep learning models tend to have a large number of parameters therefore there is a cost in terms of large amounts of data and computation resources needed to enable successful training.

## Slide 8: Gradient Descent (GD) Algorithm 

<mark>The key algorithm required for training neural networks is gradient descent. This is an optimisation algorithm that seeks to minimise the value of the loss function. Here we again represent the loss function by 𝐽(𝜃) , where 𝜃 are the parameters of the model. As shown in figure (a), the gradient descent algorithm can find the minimum of a function, such as the simple U shaped one shown. Given a random starting value of 𝜃 , the algorithm finds the minimum by moving in the direction of the steepest gradient, one step at a time. In order to minimise the function, the inputs to the function, that is the theta values, must be updated. This is done with the update rule shown in equation (1). The update requires determining partial derivatives of the loss function with respect to 𝜃 parameters. The other important parameter in the update step is eta 𝜂 . This is the learning rate, it determines how large a step the gradient descent algorithm takes on every iteration. As shown in the figure (a), a small learning rate results in the algorithm needing many updates to find the minimum. Conversely, too high a learning rate leads to divergent behaviours of the algorithm. The goal is to choose a learning rate that can find the minimum with the least amount of updates, but still remain stable. We can see the effect of the learning rate in figure (b). Here the loss function value is shown vs time for various learning rates. With a very high learning rate, the process is unstable and the loss function increases. With a high learning rate, the loss function decreases rapidly but doesn't find the minimum. With a low learning rate the loss function decreases but slowly. And finally, with an optimum learning rate the minimum of the loss function is found in a reasonable time.</mark> 

## Slide 9: Gradient Descent with Back propagation. 

In the gradient descent algorithm it is necessary to obtain the partial derivative of the loss function with respect to the individual parameters. An efficient way to obtain these partial derivatives is with the backpropagation algorithm which was first published in 1989. The backpropagation is based on the chain rule from differentiation. It is incorporated into neural network training as shown figure (a). The training data is passed through the neural network. A class prediction is made by the network for each training example. These labels along with the expected or true labels are passed to the loss function, which outputs a value corresponding to the how well the network predicted the true label values. The gradient descent algorithm will seek to minimise the value of this loss function, lower values means better predictions by the neural network. During the backpropagation step, gradients of each the neural network parameters are obtained in a computationally efficient manner using a so called backwards pass through the network. As we have seen in the last slide, this gradient information is then used to update the parameters of the neural network to incrementally reduce the loss function. Again, as we saw in the last slide, the learning rate needs to be correctly chosen to balance training speed against stability. This is very important for neural networks as they can take a long time to train, due to the large number of parameters. 

## Slide 10: Batch size in Gradient Descent 

<mark>Another very important consideration in training neural networks is batch size. That is, how much training data to use for each update of the gradient descent algorithm. The simplest approach is called batch gradient descent. In this case, all examples from the training set are applied. This approach is not practical for large datasets, the working memory required to perform gradient descent and backpropagation would easily exceed the memory that is available, even with the best GPUs. The second approach is called stochastic gradient descent. In this case, only one example from</mark> 

<mark>the dataset is applied during each iteration of the gradient descent algorithm. The gradient descent algorithm can still work with one training example, however, it converges to the minimum in a noisy manner. This behaviour can however be considered an advantage, as in a complex optimisation problem like training a neural network, some noise in the training process can allow the gradient descent to escape any local minimums encountered during training. However, using stochastic gradient descent means the neural network is very frequently updated and this is computationally inefficient to perform for every single training example. The final approach is known as mini batch gradient descent and is a compromise between batch gradient descent and stochastic gradient descent. In this case, a limited number of training examples are applied on each iteration. This means there is some noise in the training process, but having 16, 32 or 64 training images together is computationally efficient as the GPU is suited to parallel computing. The figure (b) compares the 3 types of gradient descent. As can be seen, the batch gradient descent converges smoothly to the minimum, stochastic gradient descent has noisy convergence to the minimum, while the mini batch has a limited amount of noise.</mark> 

## Slide 11: SGD with Momentum 

<mark>Training neural networks with plain stochastic gradient descent (SGD) can be difficult as the SGD algorithm may have problems dealing with regions of low gradient and local minima in the optimisation surface. The simplest upgrade to the basic SGD algorithm is SGD with momentum. This helps increase the speed of convergence as well as help escape local minima or flat regions. Momentum can be easily incorporated into the SGD update rule. We now interpret the weight update as a so-called velocity. As can be seen in equation (2), the velocity term is composed of a factor "gamma" times the previous velocity plus the regular gradient times the learning rate. The effect of including previous gradients in the update is to dampen the effect of any noise in the gradients, and this also prevents the descent from getting stuck in local minima, by preserving the general trend in the gradient. Figure (a) demonstrates a one dimensional example of  SGD with momentum. As can be seen, momentum builds as the optimiser passes through a region of large gradients. This momentum increases the step taken through the flat regions and also prevents the optimiser being stuck in the local minimum. When using SGD with momentum, the learning rate and gamma value must be set. Setting gamma close to 1 leads to larger updates, but convergence problems could arise. The value of momentum could be increased over the duration of training in line with a policy. It is noted that many DNN are trained with SGD with momentum.</mark>
