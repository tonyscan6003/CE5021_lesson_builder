## Slide 4: Image Classification with CNNs 

As we have already mentioned Deep Convolutional Neural networks, composed of many convolution layers is currently the most widely used approach for many computer vision tasks. The key property of Deep Neural networks is that they can learn in an End to End fashion. Many simple and complex image features are automatically learned by the convolution layers, and the combination of various features found in images are used to classify images by the fully connected layers at the output of the network. End to end learning is a big advantage over classical computer vision, where algorithms had to be developed by hand to both extract features and form a representation of the image that could then be discriminated by classifiers like a support vector machine. The neural network approach does have some disadvantages that should be considered when choosing a deep neural 

network for a given application. It does require large amounts of data to train neural networks, particularly from scratch. Training large complex neural networks for image classification, is also computationally demanding and requires many hours of GPU training. As we will see in a later lesson on transfer learning, we can use smaller amounts of training data with a pre-trained network to fine tune it for another application, this helps to mitigate the requirements for large amounts of training data and longer compute times.

## Slide 7: Standard Datasets 

Many of the applications we discussed on the previous two slides rely on the process of transfer learning to adapt a pre-trained network to the new application. We will discuss transfer learning in a later lesson. In order to first train a Deep Convolutional Neural network from scratch we often use a publically available dataset. Many datasets for image classification have been compiled over the last 20 years, however many of the early datasets such as MNIST and CIFAR-10 shown in figure (a) and (b) were created in the pre-Deep learning era. These datasets use small image sizes and have a limited number of classes. We can train Deep Convolutional Neural networks on these datasets, however these networks won’t perform well on images outside the training domain. These smaller datasets still have a role today as they can be used as benchmarks to test the performance of networks trained on larger datasets. They also can be used for prototyping new neural networks without incurring long training times. The ImageNet dataset was the first very large scale dataset which had enough classes and quantity of images to train very general deep neural network image classifiers. Classifiers trained on ImageNet are often used for transfer learning as we mentioned already. Often in a new image classification application, there won’t be enough data to train a 

network to a high level of accuracy, so by using transfer learning the features learned on the ImageNet dataset can be fine tuned for this new applications. A further advantage of these well known datasets is that they are often well balanced, and there is a good representation of all classes, which helps improve final accuracy on all the individual classes.

## Slide 9: Metrics (Binary Classification) 

For the image classification task the most commonly used metrics are Accuracy precision and recall. We will discuss these metrics for the binary classification first and discuss how we determine these quantities in the multi-classification case in the next slide. Figure (a) shows an example of a confusion matrix for binary classification task. The task is pedestrian detection, so there are two possible classes Pedestrian or No pedestrian. There are 4 possible outcomes as there are 2 predicted labels and 2 actual or ground truth labels. If a pedestrian is predicted and the actual label for the image is a pedestrian then this is a True Positive, if a pedestrian is predicted and the actual label for the image is No Pedestrian then this is a False Positive as we have made a detection where there was no pedestrian to detect.  If a No pedestrian is predicted and the actual label for the image is a pedestrian then this is a False Negative as we have completely missed a detection, if No pedestrian is predicted and the actual label for the image is No Pedestrian then this is a True Negative. As shown in equation (1) the over all accuracy for this task can be determined by dividing the number of correct predictions that is the True Positives and True Negatives by the total number of predictions, which is given as a sum of True Positives, True Negatives but also False Positives and False Negatives. Two more quantities often determined for classifiers are precision and recall. Precision is defined as the proportion of positive predictions that are actually correct and is calculated as shown in equation (2) by the True Positives divided by the sum of the True Positives and False Positives. A high value of precision indicates a low number of false positives and high confidence in positive predictions. Recall is defined as the proportion of positives correctly identified and is calculated as the True Positives divided by the sum of the True Positives and False Negatives. High Recall indicates few missed detections by the classifier. 

## Slide 10: Metrics (Multi-Class) 

On this slide we will discuss calculating the Accuracy, Precision and Recall for the multi-class case. In the multi-class case we usually calculate the Accuracy, Precision and Recall in a “one vs Rest” manner for each class. As shown in the equations 1 to 3, we use the same form of the equations as in the binary case, but we now need to determine individual values for the True Positives, True Negatives etc for each i<sup>th</sup> class.  In order to see how we do this we will consider a simplified case. Figure (a) shows a confusion matrix with 3 animal classes, we will consider the Cat class and display the True, and False Positives and Negatives for this class in the matrix. In the centre of the matrix the predicted label and the actual label are the same and this is the True positive. Directly above and below the True Positive the predicted label is still cat but the actual labels are dog and mouse so these predictions are recorded as false positives. To the left and right of the True positive the actual label is cat but the predictions are dog and mouse, so any of these predictions are counted as false negatives for the cat class as the cat has been missed. All other combinations of predictions and actual labels not involving the cat class are considered true negatives for this calculation. Figure (b) shows the equivalent situation for the dog class, again we see the false positives are in a column with the true positive and the false negatives lie along the row with the true positive and all other positions comprise True Negatives. Now that we can determine individual values of accuracy, precision and recall, we would like to combine them into one value that represents the overall performance of the classifier. As shown in equation 4 we can simply obtain the average of the individual accuracy values. This is called the macro-accuracy, this assigns the same importance to each class when getting the final accuracy. Therefore if there is a poor performing class, due to few examples in the training set, this will bring down the average accuracy. In contrast the weighted accuracy adds a weight depending on how many examples of each class are in the training dataset. In this case the overall accuracy score will be dominated by the largest class. In a balanced dataset with equal numbers of examples in each class the macro accuracy and weighted accuracy will be the same. We can also determine macro and weighted values for precision and recall following the same procedure. 

## Slide 11: Top 1 and Top 5 Accuracy. 

Top1 and Top5 accuracy are accuracy metrics associated with Deep Neural Network Image Classifiers on the ImageNet dataset.  Deep Neural Networks are probabilistic classifiers, that output a normalised vector of probabilities for each class. Figure (a) shows an example test image of a tiger and the outputs of two different classifiers A and B, where the horizontal bars represent the probability of each class.  Top 1 is the conventional multi-class accuracy that we discussed on the last slide. For a true positive to be declared, the highest probability prediction from the classifier must match the actual image label. We can see that the highest probability prediction from Classifier A is Tiger so a true positive is recorded and included in the accuracy calculation for the tiger class. The highest probability prediction from Classifier B is Cheetah which is incorrect so a False Negative is recorded for the Tiger Class when calculating accuracy. As Top 1 accuracy is a very stringent criterion when dealing with a challenging dataset like ImageNet with  a 1000 classes, many of which are similar, the less stringent top 5 accuracy was introduced. In this case a True positive can be recorded if the actual label matches any of the 5 highest probability predictions produced by the classifier. As we can see in the figure, both classifiers have the label tiger in the top 5 predictions, so this will result in a True positive prediction in both cases. Normally any Neural Network Classifier will score higher in Top5 accuracy than Top 1 accuracy. 

## Slide 12: Robustness, Confusion & Bias 

As we have seen in this lesson Neural Networks are trained on specific datasets for a given application. The network may have exceptional performance on test images that are drawn from the same domain as the training set, but may not perform well on test images from a different domain. For example as shown in figure (a), if a network was trained exclusively on day time driving scenes, it may not perform well on nightime scenes. Another issue observed in trained neural networks is confusion, this is a mislabelling error that occurs for similar classes. This can happen when objects or scenes share similar image features, such as the cello being labelled as violin or a library being labelled as a bookshop as shown in figure (b). Under-represented classes with fewer training images are potentially more subject to these errors, as the network will have had less opportunity to find distinguishing features for these classes. A final issue that is of great concern particularly when deploying neural networks for any application is bias. The network may learn any biases present in the training data. In the example shown in figure (c), a neural network is trained to classify the gender of a person in an image. The mislabelling of the genders occurs due to bias in training data, where images of sports activities contained a significant bias towards images of men.
