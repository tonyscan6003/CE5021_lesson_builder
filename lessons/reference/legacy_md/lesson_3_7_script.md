## Slide 2: Introduction to 2D Pose Estimation 

Pose estimation is the computer vision task of estimating the configuration of Human body parts from images or video. In this task we usually try to predict anatomic keypoints corresponding to major joints, such as knees, hips, shoulders as well as eyes, the nose or just the head. These points can be linked to form a stick diagram of the persons pose. The exact set of points to be predicted will depend on the training dataset. An example of pose estimation is shown in figure (a). In this lesson we will discuss 2D pose estimation, which involves predicting joint positions in x and y plane only. Pose estimation will share many of the challenges we have discussed for the image classification and object detection tasks. In particular pose estimation is difficult as we often have to predict the position of small joints which only corresponds to a small region in an image. As shown in figure (b) self occlusion is major problem in pose estimation, as we often can’t directly observe the position of some joints due to the orientation of the body and finally as shown in figure (c) we may have to deal with extreme articulation of the limbs, which can also make prediction difficult. Pose estimation has many applications, it can be used as a basis for action or activity detection and is very useful for motion capture and augmented reality. 

## Slide 3: Datasets 2D Pose Estimation 

As with the other vision tasks we have discussed, large scale datasets are necessary to train systems to perform pose estimation. An example of an early pose dataset is the Leeds sports Pose or LSP dataset, which contains 2000 images from 8 sports and uses 14 keypoints in each image, some example images from the dataset are shown in figure (a). If we are using a dataset with a limited number of images such as the LSP dataset, we  generally will need to use data augmentation to stop the network from overfitting. There is also an extended version of this dataset with 10k images. Another early dataset is the Max plank institute for informatics or MPII Human pose data set. This contains 25k images, from over 400 daily activities. Both the LSP and MPII datasets contain one person per training image. The Microsoft Common objects in context dataset, which we have already encountered for both object detection and semantic segmentation, also contains a keypoint detection task, which is the same as pose estimation. This dataset is much larger than the LSP and MPII datasets with 200K images. The COCO keypoint detection dataset is more challenging, as there are often multiple persons to be detected in some of the images, as shown in figure (b). A final pose estimation dataset is the AI Challenger Human keypoint detection dataset, this is the dataset with the largest number of available images with 300 thousand images. 

## Slide 4: Evaluation 2D Pose Estimation 

In the earlier lesson on object detection, we saw how we use intersection over union as a measure for quantifying how well a predicted bounding box fits the ground truth. By setting a threshold value for IoU, we can then obtain a precision recall curve for the object detector and from this obtain the Average precision. To quantify pose estimation systems we firstly require an equivalent measure to 

IoU, that allows use to see how well a predicted joint or body segment between two joints, fits the ground truth. A measure of pose accuracy using body segments, that is often seen in older publications is the Probability of Correct Pose or PCP. With PCP a candidate body part is labelled as correct if its segment endpoints lie within 50% of the ground truth endpoints. The problem with this measure is that it is sensitive to limb foreshortening, as we can see in figure (a) the limbs of the tennis player that are pointing away from the camera, for example the lower right leg and left arm, appear short due to the camera perspective. It will be more difficult to accurately predict the length of a short segment than a longer one, it is more likely a false detection will occur as a small error will be a big percentage for a small limb segment. A more commonly used measure than PCP is The percentage of correct keypoints or PCK. With this measure we look to see what percentage of the predicted joint positions are within a certain threshold distance value of the ground truth. As shown in figure (b), there is a small window with a radius equal to a threshold value around each ground truth position. The predicted joint must be inside the window for a correct detection to be registered. The threshold is selected as alpha times the max of the height or width of the bounding box around the person. The alpha value is just a scaling value and is usually be selected to be 0.2 or 0.1 times the max of the height or width. Instead of just obtaining a percentage of correct keypoints, we can use the same threshold to define true & false positives aswell as false negatives, this is the same as using an IoU threshold to define a true positives in the object detection case. Similar to the object detection case we can determine a precision recall curve based on prediction confidence values and calculate the average precision.  The metric in this case is known as the average precision of keypoints or APK.

## Slide 6: “Classical” 2D Pose Estimation 

Pose estimation has been a long standing problem in machine and computer vison. As with many other vision tasks, deep convolutional neural networks have become the primary methodology to build systems for pose estimation. On this slide we will briefly discuss the standard classical approaches to pose estimation using pictorial structures, as it is relevant to how systems using deep CNNS are constructed. In the pictorial structures approach shown in figure (a), the person is modelled as a collection of parts in a deformable configuration or Tree. Firstly the body parts or joints are detected individually in images, typically in these systems this will be performed with a classical object detector such as the HOG. Figure  (b) shows an example of part detection for the reference [3], we can see the object detector has produced heatmaps for the likely location of the head, torso and upper leg of the gymnast in the input image. The model configuration must then be fitted to the detected parts. This is a computationally difficult problem, it cannot be solved using brute force due to the number of permutations. The problem is often solved with a generative model as discussed in reference [3]. 

## Slide 7: Approaches to 2D Pose Estimation with CNNs 

With Deep convolutional neural networks, there are two primary approaches to 2D pose estimation. Firstly in regression based methods, an approach similar to object detection is taken. In object detection we directly predict the bounding box coordinates, similarly in pose estimation we directly predict the coordinates of each of the joints in the input images as shown in figure (a). Alternatively in body part detection an approach similar to the classical approaches discussed on the previous slide is taken. In this case shown in figure (b) we use the convolutional neural network to find object parts as heatmaps. We then need to associate the parts with a model structure. Due to the high quality spatial predictions for each part produced by CNN, the part association is trivial to complete. 

## Slide 8: DeepPose 

Deep pose was the first deep learning based system for 2D pose estimation. Similar to the image classification and object detection tasks, deep neural networks are capable of building a representation of images that in this case allows estimation of the position of the joints of a figure in an image. In contrast to the classical computer vision approaches, DeepPose uses a regression approach to pose estimation. The advantage of this approach is that there is no need to explicitly detect body parts and design a model topology to fit the parts to. The deepPose network uses the AlexNet architecture as it’s basis. In order to predict joint positions, the output softmax layer of AlexNet is simply replaced by a regression layer that predicts the x,y spatial positions of joints. The number of output pairs can be set to match the number of joints in the dataset being used to train the system. DeepPose uses a cascade of stages, each one consisting of an AlexNet architecture and a regression stage. Importantly DeepPose operates on regions of the image defined by a bounding box and predicts coordinates relative to the bounding box centre. This step allows different size regions to be scaled to match the input size of alexNet while guaranteeing reliable prediction of joints relative to the image center. In the first stage, a bounding box is drawn around the person of interest, usually by an object detector. The first stage then predicts multiple joint positions within the bounding box as shown in figure (a). In the subsequent stages, the bounding boxes are defined around each of the individual joint positions as shown in figure (b). The additional network stages will each predict a refinement to the joint positions as shown in figure (b). It is necessary to pass an image defined by a bounding box through the cascade of stages for each individual joint coordinate to be fully refined. This one image per joint constraint will result in a slower system. The additional 

refinement stages are necessary in order to produce accurate prediction, as joints are small spatial locations and difficult to accurately predict. 

## Slide 9: Compositional Human Pose Regression 

While the regression approach can be used to directly predict the pose of objects it is less successful than the heatmap based approaches that we will learn about shortly. The regression approaches similar to DeepPose train a loss function based on joint coordinates, which are treated independently from one another. The standard “Joint loss” for regression is shown in the box in the lower right corner of slide. The joint loss consists of the sum over all joints, of the L1 norm of the difference between the predicted and ground truth joint positions. We note that in the publication by Sun the L1 norm is used in the Joint loss function, but many other publications will instead use L2 norm.  While it is attractive to simply predict joint coordinates, the structured dependence between joints is not being exploited during training of the network and prediction accuracy is being lost. As we mentioned earlier, classical computer vision methods for pose estimation have used models of structure in order to help predict the joint locations, however we want to retain the directness of using a neural network to predict joints and do not want to add too much extra complexity by introducing structure. In the publication by Sun, it is shown how structural awareness of the joints can be included in a deep neural network, by just modifying the loss function. As we can see in figure (a), a representation of human pose shows x,y joints positions, interconnected by bone vectors. Bones are considered to be more stable than joints, that is there is less variation in the training examples between bone vector magnitudes than in positions of joints. We can define a bone vector in terms of two joint vectors. In the model shown in figure (a) all vectors are determined relative to the pelvis joint. We can then write a bone loss  function in terms of the difference between two bone vectors. The use of a bone loss instead of a joint loss is not suitable to bring structure into the loss function. Even if we base training on bone vectors we will ultimately have to obtain joint positions from the bone vectors, as this is what is required for the metrics of most datasets. As we can see in figure (a) the position of joints is obtained by summing vectors starting at the pelvis, any errors in these individual vectors will accumulate and we end up with poor joint predictions. The paper by sun introduces the composition loss functions which is based not on individual joints or bones, but the sum of bone vectors along the path to a Joint, which is given as ∆𝑱𝑢,𝑣 for a path between two joints u and v, with M bones. The compositional loss is then defined in terms of the difference between the predicted sum of bones and the ground truth sum. This compositional loss is defined as a function in terms of B, the bone vector values but also P, which defines which set of bones to use. The highest predictive performance is obtained by including all possible paths along the model. The network for this model is ResNet50 and unlike DeepPose iteration is not required due to a more complex model and the improved loss function. One key advantage of regression methods is that they can be easily adopted for 3D pose prediction with limited modification. 

## Slide 10: Convolutional Pose Machines 

The last two methods we discussed were regression based and involve direct prediction of joint positions. In this slide and the next we will look at the alternative part based approach that is analogous to classical systems. Figure (a) shows the high level diagram of  the convolutional pose machine published by Wei in 2016. This is a multi-stage system, the first stage consists of a CNN that outputs belief maps. The belief maps show the likely spatial location for each joint, with regions of high intensity corresponding to likely joint locations. The early predictions are coarse and can often be wrong, so the system has additional stages to help refine the belief maps. As can be seen in figure (a), both the input image and the belief map from the previous stage are all included as inputs to 

each stage from the second stage onwards. This helps to refine the position of the joints using information from the input image again at each stage. A key concept in the convolutional pose machine is the fact that the receptive field of the network tends to increase as you go deeper into the network. The wide receptive field means the network can learn about and make use of  the spatial relationship between parts for predictions. On the left part of figure (b) belief maps for the 1<sup>st</sup> stage of the convolutional pose machine are shown for the right elbow, right shoulder, neck and head. It is seen that the belief map for the right elbow is incorrect, but it’s position is corrected in the second and third stages, as shown on the right of the figure. This example demonstrates that the network has learned about the spatial relationship between joints, and can use the information from other joints to correct and refine any errors. Unlike the classical part based systems, that must explicitly fit a skeletal model to the detected parts, in Deep neural networks such as the convolutional pose machine, the model is learned implicitly by the network. The final location of joints is simply obtained by getting the coordinate of the max value of each belief map. The convolutional pose machine can be trained end to end and also uses a concept called intermediate supervision, which just means that a loss function is applied to each individual belief map. This forces the belief maps produced at the output of each stage to conform to the same structure, without this supervision the network could encode the information about joint position arbitrarily. Using intermediate supervision also helps with the vanishing gradients problem during training. 

## Slide 11: Stacked Hourglass 

Another example of a part based deep convolutional neural network is the stacked Hourglass shown in figure (a). Once again this is a multi stage model, like the convolutional pose machine belief maps are refined at each stage. Also similar to the convolutional pose machine, intermediate supervision can be applied and the model trained end to end. Unlike the convolutional pose machine the input image is only applied once at the input. The structure of the individual hour glass modules removes the necessity to connect the input to each stage. As shown in figure (b), the individual hourglass modules are similar to the fully convolutional networks we have seen previously for semantic segmentation. The modules have a main feedforward path, where the feature maps size is successively downsampled by convolution and pooling, this is directly followed by nearest neighbour upsampling stages. Similar to the networks we saw for semantic segmentation, the hourglass modules contains skip connections that feedforward information at different scales. The hourglass module processes and uses information at different scales and can make high accuracy predictions. To help with training, the hourglass module uses residual stages like Resnet and only uses 3 x 3 convolutions which helps keep the total number of parameters down. 

## Slide 12: Multiple Persons 2D Pose Estimation 

So far we have only looked at the case where we are predicting the pose of a single person in an image. However in some scenes it may be necessary to predict the pose of multiple persons in an image. This is a more difficult challenge than single person pose estimation as there may be occlusion and overlap between different individuals. It can be difficult for the system to determine which limbs belong to which individual. There are two main approaches to multiple person 2D pose estimation as shown in the figure on the slide. In the top down approach, we use an object detector to first locate individuals and then apply a 2D pose estimation network individually to each person. This approach is attractive as we can use a trained object detector such as RCNN to locate people, as is done in reference [6] and we don’t have to re-design the pose estimator to handle multiple people. The drawbacks of the top down approach is that occluded individuals may not be picked up by the object detector and the system has no way of distinguishing in cases of overlapping limbs. In 

the bottom up approach, we first locate all possible joints in an image and then group these joints into subjects. The bottom up approach potentially allows better quality results to be achieved but introduces the problem of determining which joints belong to which individuals. Solving this assignment problem is a whole research topic in itself, which we won’t cover in this course. The link [7] is to the recent OpenPose system which uses a bottom up approach to achieve very good results on the COCO keypoint detection task.
