## Slide 3: <mark>Processing Images with Fully Connected NN</mark> 

The simplest but naïve approach to processing images with neural networks is to use a traditional fully connected neural network. In this case we must first take the image for example the 4 x 4 pixel image shown in figure (a) and rearrange the pixels into a vector with 16 rows. We can then connect this vector to the neural network, each neuron in the network connects to each element of the vector or each pixel. As this network only has two neurons, there will be 32 parameters for the connections and 2 bias parameters. For a more typical image of size 256 x 256 the vectorised input to the fully connected network would be 65535 pixels. If the vector of pixels is connected to even a small neural network of 100 neurons, the number of parameters required is extremely large at 6,553,500. From this example we can see that directly processing medium or large images with fully connected neural networks consumes too much memory and computation and makes this approach impractical. 

## Slide 4: <mark>Why use CNNs</mark> 

On this slide we want to answer the question why convolution is used in neural networks for image recognition. As we already know, the Convolution operation in two dimensions is used in image processing to process images with filters. As shown in figure (a) an image can be blurred by simply convolving it with a gaussian filter. Filtering images in this manner allows us to do more than just blurring, we can find horizontal and vertical edges or circular regions, blobs and other patterns. A key property of convolution is that it only operates on small n x n pixel regions of images rather than the entire image. Figure (b) shows a 3 x 3 region in the image. The convolution operation involves applying the same filter to every region of the image, this is a computationally efficient linear operation. The number of parameters is equal to the size of the filter which is 9 in this example. As 

we have just mentioned these filters operate only on local regions. This is in contrast to the fully connected approach on the previous slide that considers all pixels in an image together and uses a large number of parameters. The use of convolution operations can be considered a prior in CNN architectures:  by including convolution operations in the architecture we are using our prior knowledge about how to efficiently perform image processing functions with convolution. A key difference between convolution operations used in image processing and convolutional neural networks, is that the convolution kernel parameters are learned during training in convolutional neural networks, whereas in image processing the kernel is specified in advance.  As we will see in the many examples of CNNs in this module,  using Convolution in neural networks has been proven to be an excellent approach to achieve high accuracy on many recognition tasks with good computational efficiency. 

## Slide 5: <mark>Convolution as a Neural Network.</mark> 

On this slide we will discuss how convolution operations can be interpreted as a neural network. To understand this we will look a simple convolution of a 3 x 3 image with a 2 x 2 kernel. Assuming no zero padding, there are 4 positions in the image the kernel can visit, and a 2 x 2 output feature map results. We can interpret each position of the kernel in the image as part of a neural network, as shown in the lower part of the image. We draw the image pixels as a column vector and assume that each position of the kernel corresponds to a neuron. As we saw in a previous lesson, a neuron consists of a sum of weights multiplied by the inputs plus a bias, a neuron also contains a non-linear activation function such as sigmoid or relu acting on the sum. The multiply and sum operation of the kernel at each position in the image is the same as the weighted sum in a neuron with a limited number of connections. We just need to include a bias term and an activation to make the convolution mathematically the same as a neuron. As shown can we repeat this for each position of the kernel until we get the final network. We note that the resulting network looks like the fully connected networks we have seen previously, very importantly however the network is not fully connected, which saves computation. The exact same set of parameters are used for each neuron which saves memory. One final point to note is that in actual convolutional neural networks we do include an additional bias parameter, which is added to each neuron (we haven’t shown the bias being added in the example shown). As the 4 neurons in the figure share the same kernel or weight parameters, they also share the same bias parameter. 

## Slide 5: <mark>Structure of a CNN.</mark> 

Having discussed in this lesson how convolution can be used to form a neural network we can now look at the basic structure of a CNN. In figure (a) we use an alternative way of showing a network. Rather than showing the feature maps as was done in the last lessons, we can instead show the operations as layers and from these infer the size of the feature maps. In the figure we can see the initial use of convolution layers with 3 x 3 convolutions and N kernels, the padding is denoted as “Same”, ensuring the input and output feature maps will be the same spatial size. The activation required to make the convolution layer function properly as a neural network is shown explicitly as a layer. It is good practice to show the activation functions, as in modern CNNs, convolution layers may appear without activation in certain circumstances. We see that we often stack convolution layers, to produce deeper networks which helps the network to learn complex features.  Pooling layers are often found in CNNs, they summarise the features, either by averaging or taking the max value in a region as shown in this example. Pooling also reduces the spatial size of the feature maps, this helps reduce computation. As shown in this example the number of kernels in the convolution is increased as the spatial size is reduced after a pooling layer. This network includes further 

convolution stages and then adds a second pooling layer. From this point we want to take the information from the last feature map and obtain prediction of a class. In order to do this we must convert the feature map to a vector, this is performed in the flatten layer, this vector can then be applied to a dense layer with 10 neurons. The number of neurons is chosen to be the same as the number of classes, the softmax activation converts the output of the neurons to a class probability. 

## Slide 7: <mark>Learned features.</mark> 

As we have already mentioned, during training the parameters of the kernels in the convolution layers of the network are learned. It may be helpful to think of convolution layers as performing cross correlation with the image. The convolution layers after training therefore find the learned features in the image. As shown in the figure on the right hand side, the early convolution layers have learned simple features such as lines and edges. In deep convolution layers much more complex features which resemble entire objects have been learned. The responses to learned features that appear in the output feature map for a given input image, are then interpreted by the classifier stage and a class probability output. 

## Slide 8: <mark>Receptive Field</mark> 

<mark>An important concept in CNNs that is dependent on convolution and pooling layers is the receptive field of the neurons. The receptive field is defined as the size of the region in the input a neuron can view or respond to. This is important for object recognition and image classification, as the receptive field must be large enough to detect objects of interest. The receptive field of a neuron is determined by the preceding convolution and pooling layers. Figure (a) shows a simple neural network with 1 dimensional data. The network has two convolution layers with kernel size 3 and stride 1 with one ring of padding. There is also one intermediate pooling layer with a kernel of size 2 and stride 2. The receptive field of any neuron can be determined by working backwards through the network. In figure (b), we consider the point B in the output feature map of the pooling layer. As we know, the pooling operation has a pooling window of size 2. We can highlight the two pixels in the preceding layer that contributed to B. This middle layer was formed by convolution of 3 x 3 kernels with the input. Thus, a region of 4 pixels wide contributed to the 2 output features in the middle layer. Thus, capital B has a receptive field of 4 pixels. In figure (c), we consider the output feature capital C. In this case, by following the same methodology we find that the receptive field is 7 pixels. As we go deeper into a network, the receptive field size generally increases.</mark> 

## Slide 9: <mark>Translation Invariance</mark> 

<mark>Another important property of CNN is translational invariance. This is the ability of the network to give the same response no matter where in an image an object is located. For example if an image contains a cat as the main subject, we want the network to correctly classify the image no matter where in the input image the cat is located. Convolution layers automatically build in translational invariance to the network, as the same convolutions or feature detection is applied everywhere in the image. Pooling layers also contribute to translation invariance. In figure (a), a max pooling operation with a kernel size of 3 is applied to the 1dimensional data. In this example, red represents the large values and blue to lowest. As we can see, the red dot is the retained value in the centre pixel of the pooled layer. In figure (b), the 1dimensional data is shifted by one pixel. The red dot is still captured by the same pooling window, and is still the maximum value in that window and is therefore retained again by the pooling layer. Thus, we can see from this example the pooling layer has the same result in both cases. This invariance to translation may help the network identify objects that have shifted in position.</mark> 

## Slide 9: Simple CNN 

<mark>Given the basics of convolutional neural networks that we have covered in this and previous lessons, we are now in a position to understand the structure of a simple convolutional neural network. The network that we will look at is LeNet-5, which was developed in 1998 to perform handwritten digit recognition. An example of the handwritten character MNIST dataset is shown in figure (a). The network and a table summarising the layers is shown in figure (b). The network is represented in a typical fashion, which plots the feature maps resulting from convolution and pooling operations, and also shows 1D vector outputs from fully connected layers. As shown by the arrows, convolution takes place in between the output feature maps. Each output feature map becomes the input for the next layer. This neural network is not very deep, it only has 2 convolutional layers, 2 pooling layers and 3 fully connected layers at the end to perform classification. It also operates on small greyscale images of size 32 x 32. The first convolutional layer has kernels of size 5 x 5 and there are 6 output feature maps of size 28 x 28 produced. The number of kernels must be equal to the number of output feature maps. The kernels only have one channel as they are convolved with the greyscale input. After this convolution, an average pooling operation is applied. This reduces the size of the feature maps from 28 x 28 to 14 x 14, which indicates a stride of 2. The number of channels stays the same during pooling operations. After this, another convolution operation is applied, as there are 16 output feature maps, there must be 16 kernels which now must have 6  input channels. The output feature maps of the second convolution are then pooled again, reducing the feature map size to 5 x 5 x 16. At this point, the network transitions into a fully connected section, consisting of 3 layers with 120, 84 and 10 neurons. A flatten operation, which is not shown, must be employed to convert the output feature map to a 1D vector input to the fully connected layers. The last layer has 10 neurons equal to the number of classes in the MNIST dataset and softmax activation is applied so a probability for each class can be output. There is no rule to choosing the exact number of convolution layers, kernels, pooling layers or fully connected neurons to use for any particular application. It will take a designer many trial and error attempts to find the correct level of complexity needed for a given deep learning application.</mark>
