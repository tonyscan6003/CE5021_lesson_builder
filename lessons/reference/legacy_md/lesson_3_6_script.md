## Slide 2: Context Knowledge 

<mark>As we saw in the first part of this lecture, DCNNs for image classification with some modification are used for pixel level prediction. The context or spatial information about a scene is reduced by the CNN pooling or downsampling layers. However, as we have mentioned, the semantic information about the scene or objects in a scene increases as we pass through the network. The figures on this page show how semantic segmentation networks can, however, mislabel objects due to a lack of context or spatial information. For example, some pixels in the window of the bedroom are labelled as a door, while in the image of the lake the boat is misclassified as a car. If our semantic segmentation system had a very high-level knowledge of the context of the image it would know that we are unlikely to find a car in water and that this object was more likely a boat. If you are interested, you can read more about how to introduce this type of reasoning into a semantic segmentation network in the reference [1]. However, it is more generally assumed that designing the semantic segmentation network to have a larger receptive field allows the deep neurons in the network to also the capture context or spatial information more accurately. In the example of networks from the last lesson, we saw that we could use spatial information, such as skip connections, to improve pixel level accuracy. In this lesson, we will see the techniques of dilated convolutions, pyramid scene pooling and also the use of conditional random fields.</mark> 

## Slide 3: Dilated Convolutions 

<mark>A very popular way to increase the receptive field of neurons in a network is to use dilated convolutions. These are also known as Atrous convolutions. Dilated convolutions are not to be confused with the transpose or fractionally strided convolutions we saw in part A of this lesson. In a dilated convolution, the input samples are spaced out and the convolution is performed with these samples. It is very important to note that the number of parameters stays the same. As we can see in figure (a), when a regular 3 x 3 convolution is applied to the input feature map, 9 adjacent pixels contribute to one pixel in the output feature map. The receptive field size for this feature map is thus 3 x 3. If a 3 x 3 dilated convolution, with a dilation factor of 2 is applied to this output feature map, it has a much wider receptive field of 5 x 5. In the final output feature map, each pixel has a receptive field of 7 x 7. We can see how this obtained by including the receptive fields, marked in green, from the first convolution under each sampled pixel in the dilated convolution. Cascading dilated convolutions produces exponential growth in the receptive field for only linear growth in parameters. This property makes dilated convolutions an ideal choice to use in a network for semantic segmentation and this technique has been widely adopted. The regular convolution layers of an architecture, such as VGG, can be easily replaced with dilated convolutions for no additional computational cost and the receptive field greatly widened.</mark> 

## Slide 4: Pyramid Scene Parsing 

<mark>An additional technique that can also improve semantic segmentation is pyramid scene parsing. This technique is similar to spatial pyramid pooling that we saw in object detection. As in spatial pyramid pooling, spatial information about the location of different features in the output feature map of a network are retained. As can be seen in figure (a), the ResNet network is used as the backbone of this system. Certain convolutions are replaced with dilated convolutions to increase the receptive field size. The output feature map is pooled to produce further output features maps with different spatial dimensions. These output feature maps then have their depth reduced by further convolution. An upsampling operation is applied to each of these feature maps and they are concatenated with the original output feature map. The result of this pooling operation is that spatial information at different scales is aggregated. A final convolution layer is then used to produce a pixel level prediction. It is noted that this approach to semantic segmentation is different to that which we have seen in the last lesson. We no longer rely on a decoder type network and skip connections to obtain a semantic reconstruction of the fine detail of an image. Instead, by using the dilated convolution, the effective down sampling of the network is reduced and along with pyramid scene parsing or other techniques that help retain spatial information, a good semantic reconstruction of the input image can be obtained without a decoder.</mark> 

## Slide 5: Conditional Random Fields 

<mark>Conditional random fields (CRF) can be used to explicitly model relationships between pixels. The pixel intensity and position are used to predict the pixel label. The CRF can be considered to be a fully connected graph, as shown in figure (a,) where a weighting between nodes helps determines if the pixels are likely to belong to the same class. The CRF have been used in machine vision for semantic segmentation prior to the adoption of deep learning. It is also  a discriminative model like a neural network. It is computationally intractable to learn a CRF model for a large image at the pixel level. However, efficient algorithms such as Dense CRF allow approximate solutions to be found with reasonable computation. The figure (b) shows the performance of a CRF vs the ground truth for some image. On their own CRFs can produce reasonable performance. However, they are often included as a post-processing step in semantic segmentation systems, using deep learning to achieve state of the art results.</mark> 

## Slide 6: DeepLab 

<mark>A very well-known and state of the art segmentation framework is DeepLab. The DeepLab framework uses a backbone network such as VGG or ResNet, but with dilated convolutions replacing some of the regular convolutions. This reduces the effective downsampling of the network without increasing the total number of parameters. A spatial pyramid pooling stage is included to help with objects of different scale. Instead of learning a deconvolution stage, DeepLab just uses bilinear interpolation from the output feature map, there are no skip connections required. A conditional random field is used in DeepLab as post processing method to further increase the performance of the segmentation. It is noted that the CRF can be co-trained with the DCNN or the entire system can be interpreted as a RCNN.</mark> 

## Slide 7: Instance Segmentation 

<mark>We will now briefly turn our attention to instance segmentation, which combines the object detection and semantic segmentation tasks. The goal of instance segmentation is to identify</mark> 

<mark>different instances of the same object in a scene. As we saw in the lecture from section 2 on region proposals, segmentation was considered to be the more fundamental task than object detection. By first segmenting an image into regions, we can use these regions as object proposals with an image classifier for object detection. Similarly, many instance segmentation systems use the approach of performing segmentation before any recognition or classification. As shown in figure (a), if we can generate object proposals, which we now call a segmentation proposal, we can then use a DCNN to perform image classification and the pixels of each proposal can be labelled as a unique instance. As shown in figure (b), a second way to perform instance segmentation is to use a network specifically designed for semantic segmentation. Initially, a sematic segmentation is performed of a scene. As expected, multiple instances of objects, such as the people, are coloured the same. In order to perform an instance segmentation, object proposals must be generated to "cut" the semantically segmented regions into instances. Both of these methods are cumbersome and may not be trained end to end. The state of the art in instance segmentation is Mask RCNN, which is a refinement of the Faster RCNN object detection system. As we will discuss on the next slide, Mask RCNN involves the simultaneous prediction of class labels and a binary mask identifying the region of the object instance. The instance segmentation is added to the original object detection system with a very low computational overhead.</mark> 

## Slide 8: Mask RCNN 

<mark>In Mask RCNN, we predict an m x m mask for each object with a full convolutional network applied to the region of interest (RoI), which has been determined by the region proposal network. By using convolution on the output path, the outline of the object can be retained from the output feature map. In order to produce an accurate output mask, the RoI pooling stage in faster RCNN is replaced by the RoI align stage in Mask RCNN, as shown in figure (a). In faster RCNN. the RoI pooling stage will convert a region of interest, which can be any shape or size, into a fixed size output, which can then be processed by the classifier and bounding box predictor. The region proposal is generated by the region proposal network as a set of coordinates. In RoI pooling, the region proposal is quantized to the output feature map. Pooling is applied within bins of the region. These are sized to give a fixed size output to the bounding box classifier. In figure (b), 2 x 2 bins are shown but in the actual implementation, 7 x 7 bins are used. In the Mask RCNN case, the RoI pooling is replaced by RoI align. In this case, no quantization of the region proposal is performed (as shown in figure c) and the output feature map values are instead interpolated to points in the bins of the region of interest. This approach helps to preserve the spatial correspondence of the features used to generate the mask within the proposed region of interest. It is found that this no-quantization approach is the key to good mask prediction.</mark> 

## Slide 9: Mask RCNN Output 

<mark>On this slide, we show the output of RCNN. We should note that the output masks produced by Mask RCNN are low resolution and are projected onto the original image. The limited resolution is due to the size of the mask path produced by the RoI align operation. The output also predicts k masks with one per class. Only the mask that corresponds to the predicted class from the class prediction branch of RCNN is used. The predicted bounding boxes are also overlaid in the images.</mark>
