# Object Detection (Part A): Two Stage Object Detection with Region Proposals 

## Slide 1: Title Slide 

<mark>In this two-part video lesson, we will discuss object detection with Deep Convolutional Neural Networks. In this first part, we will consider frameworks that use region proposals to achieve high accuracy object recognition.</mark> 

## Slide 2: Object Detection with Region Proposals 

<mark>In the introduction to this section we introduced the idea of using region proposals to reduce the amount of computation required in an object detection system by reducing the number of calls made to the classifier for any given input image. In this lesson we will focus on the R-CNN object detection framework and it’s variants. R CNN where R stands for region was one of the first and most well known object detection systems. The original RCNN has several problems which we already encountered in the introduction and will recap again here. In this lesson will also discuss the solutions to these problems which were adopted in the successors to RCNN, the Fast and Faster RCNN architectures. Figure (a) shows again the object detection system with a region proposal generator and an image classifier. As we mentioned previously the region proposal generator will generate region proposals of different shapes and sizes. This creates a problem for neural networks that require fixed size input images. This problem is solved initially in RCNN by warping the image regions to a fixed size, however as we’ll see architectural modification of the neural network to allow arbitrary sized inputs is a much more elegant solution. This can be achieved with the spatial pyramid pooling and region of interest pooling as demonstrated in the Fast RCNN architecture. Another obvious problem is that the image classifier operates on overlapping regions of the image several times, this is not very computationally efficient. As we will see a technique called Region of Interest projection introduced in the Fast RCNN architecture allows the entire image to be processed once by the convolution layers of the network. The features can then be operated on independently to detect objects. A major issue with the RCNN system, is that is uses a separate selective search region proposal algorithm, this prevents end-to-end training of the system. The Faster RCNN algorithm replaces the selective search with a neural network equivalent, which helps end to end training.</mark> 

## Slide 3: C1: Use of Convolutional Features 

The RCNN framework was one of the first examples of using transfer learning. Figure (a), shows a typical machine learning system where images are converted into feature vectors which can be classified by a support vector machine. In RCNN the classical representation consisting of engineered features, is replaced with a pre-trained convolutional neural network, which has learned it’s features on the image classification task. The classification is still performed by a support vector machine, which means the classifier is trained independently of the Convolutional Neural Network, so this system does not allow end to end learning. 

## Slide 4: RCNN (Region CNN) 

<mark>The Region CNN or RCNN is considered one of the most important developments in deep learning along with AlexNet and ResNets. The RCNN system consisted of a multi-stage pipeline. Initially, as shown in figure (a), selective search is used to identify region proposals within the input images that contain objects. As selective search produces different sized regions of interest, these regions must</mark> 

<mark>be warped to a consistent square size that is compatible with the input size of AlexnNet. These image patches produced by selective search are then used to fine-tune the weights of AlexNet, which is modified to have a reduced number of classes compared to ImageNet. Once AlexNet has been fine-tuned, the full connected portion is removed and the convolution part used as a feature generator. Next, the classifier and bounding box regressor must be trained. The set of warped regional proposals are sorted into binary categories such as "car" and "not car", features are then extracted from these image patches and the extracted features are used to train a support vector machine (SVM) for each class. The bounding box regressor is also trained using CNN extracted features. This is shown in figure (b). Figure (c) shows the system operating in inference mode; in this case, the regions proposals are generated for the new image, warped to the appropriate size, features are extracted by the CNN and classification and bounding boxes predicted by the SVM and regressor. The initial RCNN system, while it works quite well, has some disadvantages. The most obvious is that each stage must be trained individually. We need to train the selective search, retrain the CNN, and also train the SVM and bounding box regressor. It is also computationally slow, as each region proposal generated by an image is processed by a CNN; there may be 100's of candidate region proposals for an image. This much more computationally intensive than image classification, where each image needs only to be processed once. In order to train the SVM and bounding box regressor, the features produced for each training example must be stored; this requires 100's of GB of memory.</mark> 

## Slide 5: Towards End to End Learning for Object Detectors 

The RCNN and its variants that we see in later slides are conceptually 2 stage detectors. The first stage consists of the region proposal generator and the convolution layers, that convert the region proposal to a feature vector. The second stage operates on this vector and predicts the object class and a refined bounding box within the region proposal. A simplified RCNN system operating in inference mode is shown in figure (a). The original RCNN uses the output of convolutional layers as feature vectors that are input to a support vector machine and bounding box regression stage. In order to obtain fixed sized feature vectors to send to the SVM, we must warp the region proposals before inputting them to the convolution layers. The first step towards improving the original RCNN system and enabling end to end training, is to replace the support vector machine and bounding box regression stage with fully connected neural networks. The neural network can perform the same functions of predicting class and bounding box on the region proposals, but now can interface directly with the convolution layers and offers the ability to train the system in a more end to end fashion. However the same requirement of passing a fixed sized vector for each region proposal still exists when using a full connected neural network and warping before convolution would still be required. On the next slide we will discuss spatial pyramid pooling which allows warping to be removed and still allow a fixed sized vector to be supplied to the fully connected layers. 

## Slide 6: C2: Spatial Pyramid Pooling 

<mark>In the design of the RCNN and as shown in figure (a), the region proposals had to be warped to a specific size in order to be compatible with the input shape of AlexNet. This size limitation arises from the fully connected layers of the network, not the convolutional layers. Convolution layers can take arbitrary sized inputs. The result of changing the input spatial dimension is the spatial dimension of the output feature maps changes. In contrast, fully connected layers expect a fixed size input. Usually the output of the last convolution is reshaped into a 1 x n vector that can be input to the fully connected layer. In order to ensure the vector at the input to the fully connected layer is the correct shape, the input size must be constrained. A so-called "Spatial pyramid pooling" layer is introduced by He in 2014. As can be seen in figure (a) this allows any size input image to be sent to the network, the fully connected layers still however receive a fixed input size vector. In SPP, max</mark> 

<mark>pooling layers are used at different scales to produce the fixed length vector. As shown in figure (b), we create a three level pyramid, at each level a different size of pooling window is used, with a bigger window corresponding to a coarser scale. In order to accommodate different output feature maps sizes, that is different H,W, the pooling window size changes accordingly. As seen in figure (b) pool window is scaled by 1,2 and 4. Thus, in each max pooling operation the same size volume results. These volumes are reduced to sub-vectors of 1 x 1 x the number of channels and concatenated into one longer vector, which is sent to the fully connected layer. SPP can be included in any network, however it will need to be retrained, in order to include this layer.</mark> 

## Slide 7: Fast RCNN 

<mark>On this slide we will focus on the Fast RCNN system which has improved training time, reduced computation and increased speed compared to the original RCNN. As we mentioned already, the RCNN object detector required individual training of the different parts of the system. In the revised fast RCNN system shown in figure (a), the focus was on enabling end-to-end training. The separate SVM classifiers and bounding box regressor have been removed and fully connected layers introduced to perform for both the class predication and bounding box regression on the proposed regions. These can be trained simultaneously using a multi-task loss function. We will discuss loss functions for object detection more in the next lesson. In the conceptual RCNN systems we discussed on the previous slide, it was assumed that the region proposals were applied to the convolution layer one by one. This is computationally inefficient as overlapping regions are processed by the convolution layers multiple times. With region of interest projection, the complete image is processed by the convolution layers, and the regions are instead defined on the output feature map. Over the next two slides we will discuss the principles behind region of interest projection.</mark> 

<mark>With region of interest projection in place, the second stage of the system operates now on regions from the output feature maps of the convolution layers. However the same issue of connecting different sized inputs to fully connected layers still remains. In RCNN, region of interest pooling is employed to reduce the different output feature map regions to a fixed size volume. The region of interest pooling is implemented as just a single level of Spatial Pyramid Pooling. Some examples of region of interest pooling are shown in figure (b), the output dimensions from the ROI pooling operation are fixed and independent of the original size of the region of interest.</mark> 

## Slide 8: Class Activation Maps 

<mark>On this slide, we will discuss class activation maps, which demonstrate how information about the spatial location of objects is present in the output feature maps of convolutional neural networks, and how this information not only enables region of interest projection as seen in Fast RCNN, but also the use of region proposal networks seen in Faster RCNN. The papers by Oquab and Zhou, show how within image classification CNNs there is already a built in indication of object location based on activation or feature maps. It is possible to generate a class activation map for every image, which visualises the region of the image, which most strongly activates the identified image class. Figure (a) shows how a class activation map is easily obtained for a Deep CNN for image classification. In the final convolution layer, each channel of the feature map has some spatial distribution with low and high activation values. By using global average pooling the information in each channel is converted to a single value. Combining these channel values yields a one-dimension vector that can be processed with one fully connected layer. As shown in figure (a), this fully connected layer makes a decision on the class of the image based on a weighting of the values in the vector produced by global average pooling. Based on the identification of a particular class in an image (such as Australian terrier), these weights can be used to sum the activation maps in the last convolution</mark> 

<mark>layer to produce a class activation map. Figure (b) shows class activation maps for various classes of images. Class activation demonstrates that CNNs additionally learn to perform unsupervised object detection while training for image classification with labels only. The fact that object information has been demonstrated to be spatially located in the convolution layer output feature map, allows region of interest projection as discussed in more detail on the next slide. This information can also be used to directly predict region proposals and replace selective search, as we will see in the discussion of Faster RCNN.</mark> 

## Slide 9: C3: Region of Interest Projection 

<mark>As we have seen in the discussion of class activation maps, the spatial position of objects in the original image is retained in the output feature maps of the convolution layers of the image classifier network used as the backbone of the object detector. In the Fast RCNN this principle used to project the region proposals generated by selective search for the original image onto the lower resolution output feature maps as shown in figure (a). The main advantage of region of interest projection is that it allows convolution to be performed just once, as opposed to per region proposal as was done in the original RCNN. Figure (b) highlights the region of interest projection in Fast RCNN, the regions of interest of varying sizes are converted to a vector of standard size by region of interest pooling as discussed in an earlier slide. These vectors are iteratively processed by the backend of the Fast RCNN network to predict classes and bounding boxes. The disadvantage of the region of interest projection as used in Fast RCNN is that selective search is still used to determine the original region proposals on the image. This algorithm is trained independently from the rest of the network, so the system does not yet have true end to end training capability.</mark> 

## Slide 10: C4: Region Proposal Network 

<mark>In the final evolution of RCNN, the focus is on the elimination the external region proposal generator. As we have seen in the discussion of class activation maps, object location information is already available within the backbone CNN that we use in the object detection system. The authors of Faster RCNN use the convolutional feature information as an input to a small region proposal network (RPN). The RPN can be considered to be part of a larger CNN that shares its convolution layers with the feature generating CNN, we will discuss the RPN layers in more detail on the next slide. Training the RPN is end to end, however it involves an alternating training scheme with the Fast RCNN part of the system. The RPN is initially trained, then the fast RCNN portion of the network is trained using RPN proposals. The common convolution layers of Fast RCNN and the RPN are fixed and only the RPN part is trained. Finally, the common part of the network is again fixed and the RCNN part fine-tuned. In part B of this section, we will see single stage object detectors that do not include region proposals and are simple to train.</mark> 

## Slide 11: Comparison 2 Stage and Single Stage 

<mark>In the next lesson we will discuss single stage object detectors, however we will compare the two types in this slide in order to see the key similarity between Faster RCNN and single stage object detectors. As can be seen in Figure (a) Faster RCNN can be described as a two stage detector, with the first stage involving prediction of bounding boxes on the input image by the region proposal network and then these boxes are projected onto the output feature maps by region of interest projection. In the second stage the regions of the output feature maps are converted to a vector by region of interest pooling and refined bounding boxes and classes predicted. A single stage detector predicts bounding boxes and class directly from the output feature map. The region proposal network and single stage detector are functionally equivalent. The additional stage in a 2 stage detector provides more accurate bounding box estimation and classification, however this comes at the cost of a slower frame rate. Modern single stage detectors have closed the gap in accuracy on 2</mark> 

<mark>stage detectors and also have higher frame rates, making them the default choice in many applications.</mark> 

## Slide 12: Summary 

<mark>Object detection with Deep Convolutional neural networks has rapidly advanced in parallel with image classification. In this lesson, we have focused on the RCNN family of object detection systems. The RCNN family uses region proposals for object detection, which helps achieve high accuracy. In part B of this lesson, we will look at single stage object detection systems, which do not use region proposals. The RCNN family can be considered to be an object detection framework. In addition to the original RCNN publications, there are many variations of RCNN by other authors using a variety of different enhancements and different backbone networks. These variations may change the accuracy, computational load or suit specific applications. To finish, we will summarise the key advances in the RCNN family. The original RCNN was amongst the first successful systems to use CNN features for object detection, as opposed to the traditional handcrafted approaches developed in the early 2000s. Fast RCNN greatly refined the system by introducing region of interest pooling and CNN based classification and regression stages for end-to-end training. A reduction in the required computation was obtained by only needing to use the CNN once per image. Finally, Fast RCNN introduced a region proposal network to remove external region proposal generation.</mark>
